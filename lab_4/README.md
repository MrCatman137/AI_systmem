# Laboratory Work 4: Wavefront algorithm on a Maze

This CustomTkinter application demonstrates unidirectional and bidirectional Wavefront search in a maze. It supports animation, step-by-step execution, four-way, diagonal, and eight-way transitions, maze editing, and JSON/TXT persistence.

## Run

From the repository root:

```text
python lab_4/main.py
```

Install the only external dependency when needed:

```text
python -m pip install -r lab_4/requirements.txt
```

The initial graph is deterministic and is never randomly generated.

The laboratory page also has a random graph generator.
