# Laboratory Work 3: Wavefront algorithm on Graphs

This CustomTkinter application demonstrates Wavefront search. Support animation, step-by-step execution, traversal orders, reverse search, result comparison, graph editing, and JSON persistence.

## Run

From the repository root:

```text
python lab_3/main.py
```

Install the only external dependency when needed:

```text
python -m pip install -r lab_3/requirements.txt
```

The initial graph is deterministic and is never randomly generated.

The laboratory page also has a random graph generator.
